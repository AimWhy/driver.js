## Popover

You can either use the default class names and override the styles or you can pass a custom class name to the `popoverClass` option either globally or per step.

Alternatively, if want to modify the Popover DOM, you can use the `onPopoverRender` callback to get the popover DOM element and do whatever you want with it before popover is rendered.

Have a look at the [theming guide](/docs/theming#styling-popover) for a detailed guide, including the class names to target.

### Using Hooks

To change the popover's DOM, for example to add your own buttons, use the `onPopoverRender` hook. See [Custom Buttons](/docs/popover#custom-buttons) for an example.

## Overlay

You can customize the overlay opacity and color using `overlayOpacity` and `overlayColor` options to change the look of the overlay.

> **Note:** In the examples below we have used `highlight` method to highlight the elements. The same configuration applies to the tour steps as well.

### Overlay Color

Here are some driver.js examples with different overlay colors.

```js
import { driver } from "driver.js";
import "driver.js/dist/driver.css";

const driverObj = driver({
  overlayColor: 'red'
});

driverObj.highlight({
  popover: {
    title: 'Pass any RGB Color',
    description: 'Here we have set the overlay color to be red. You can pass any RGB color to overlayColor option.'
  }
});
```

## Checklist

[Checklists](/docs/checklists) are styled with plain CSS: an accent color for
the quick win, or your own class for a full theme.

### Accent Color

Set the `--driver-checklist-color` variable to recolor the progress bar, the
ticks and the focus rings while keeping the default look:

<ChecklistSample
  idPrefix="styling-checklist-color"
  buttonText="Green Checklist"
  config={{ className: "docs-checklist-green" }}
  client:load
/>

```css
:root {
  --driver-checklist-color: #16a34a;
}
```

### Custom Theme

Pass `className` to add your own class to the widget, then style its parts. The
example below is the theme used on the driver.js homepage:

<ChecklistSample
  idPrefix="styling-checklist-theme"
  buttonText="Themed Checklist"
  config={{ className: "checklist-brutalist" }}
  client:load
/>

```js
checklist({
  id: "onboarding",
  className: "checklist-brutalist",
  items,
});
```

Its CSS, and more themes ready to copy, are on the
[Checklist Themes](/docs/checklist-themes) page.

### Class Names

These are the classes you can target:

```css
.driver-checklist {}                  /* The widget, positioned in a corner */
.driver-checklist-bottom-right {}     /* or -bottom-left, -top-right, -top-left */
.driver-checklist-complete {}         /* Added once every item is done */

.driver-checklist-launcher {}         /* The button that opens the panel */
.driver-checklist-launcher-text {}
.driver-checklist-launcher-count {}   /* "1/4" */

.driver-checklist-panel {}
.driver-checklist-header {}
.driver-checklist-title {}
.driver-checklist-description {}
.driver-checklist-close-btn {}

.driver-checklist-progress {}
.driver-checklist-progress-bar {}
.driver-checklist-progress-fill {}
.driver-checklist-progress-text {}    /* "1 of 4" */

.driver-checklist-items {}
.driver-checklist-item {}
.driver-checklist-item-done {}        /* Added to an item once it is done */
.driver-checklist-check {}            /* The circle; a button with allowManualComplete */
.driver-checklist-item-trigger {}     /* The item's link, button or plain row */
.driver-checklist-item-title {}
.driver-checklist-item-description {}
```

The widget also sets `--driver-checklist-progress` to the progress as a
percentage, for progress designs drawn in CSS, like the
[progress ring](/docs/checklist-themes#progress-ring). The font follows the
popover's `--driver-popover-font-family` variable. See the
[Checklists guide](/docs/checklists#customizing) for position and text options.
